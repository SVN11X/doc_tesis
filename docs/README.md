# docs

La intención y el conocimiento de este repositorio, para personas y herramientas de IA.

- Va aquí: `goals.md` (para qué existe este repositorio, lo escribe el dueño), `how-it-works.md` (el flujo de principio a fin, las partes con sus rutas, por dónde empezar a leer y cómo comprobarlo), `glossary.md` (términos compartidos), `assumptions.md` (lo que se dio por cierto sin confirmar), `decisions/` (un registro por decisión), `specs/` (especificaciones para cambios grandes), `en/` (el README principal en inglés), `defense/` (material de la defensa), `submitted/` (el PDF entregado) y otra documentación del proyecto.
- No va aquí: contenido del producto para el usuario final ni archivos generados por la compilación.
- Nombres: kebab-case, por ejemplo `api-overview.md`.
