# Defense

Material for the thesis defense.

- `slides-v2.pptx`: the presentation, 28 slides.
- `script.md`: what to say on each slide, in Spanish.
- `images/`: every image the slides use, named by the first slide that shows it, plus `images/logos/`. Images that exist only inside the presentation were extracted byte for byte, so they keep the quality stored in the `.pptx`.

The rehearsal recordings and their feedback are private and stay on the owner's computer.
