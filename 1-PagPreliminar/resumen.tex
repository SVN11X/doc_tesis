El presente trabajo de titulación describe el diseño e implementación de un prototipo de robot móvil diferencial capaz de generar un mapa 2D de su entorno y navegar de forma autónoma. El sistema integra el \textit{middleware} \gls{ROS2} Foxy sobre Ubuntu 20.04 ejecutado en una Raspberry Pi 4, con control de bajo nivel delegado a un \gls{Arduino} conectado a un driver L298N mediante encoders de cuadratura.

La percepción del entorno se basa en un escáner láser RPLidar A1, empleado tanto para la construcción del mapa como para la detección de obstáculos. El control diferencial se implementó mediante \texttt{ros2\_control} con el \texttt{diff\_drive\_controller}, y la sintonización de las ganancias PID del firmware se realizó mediante un procedimiento híbrido: un algoritmo de optimización por enjambre de partículas (PSO) identifica el modelo dinámico de primer orden con retardo (FODT) de cada motor y calcula ganancias iniciales, que luego se refinan experimentalmente sobre el hardware real.

La validación se realizó primero en simulación con Gazebo, verificando cinemática, odometría y control, antes de transferir la configuración al hardware real, manteniendo paridad de tópicos y estructura de parámetros YAML. El mapeo se realizó con \texttt{slam\_toolbox} en modo asíncrono en línea, con optimización de grafo mediante Ceres (Levenberg–Marquardt) y cierre de lazo activado. La navegación autónoma se implementó con Nav2, utilizando el planificador global NavFn (A*) y el controlador local DWB, orquestados mediante un árbol de comportamiento con replanificación a 4~Hz y una secuencia de siete acciones de recuperación. Se integró además un módulo de exploración autónoma basado en detección de fronteras que permite al robot generar sus propias metas de navegación hacia zonas no exploradas del mapa, sin intervención manual.

\addcontentsline{toc}{chapter}{ABSTRACT}

The present thesis describes the design and implementation of a differential mobile robot prototype capable of generating a 2D map of its environment and navigating autonomously. The system integrates the \gls{ROS2} middleware Foxy on Ubuntu 20.04 running on a Raspberry Pi 4, with low-level control delegated to an \gls{Arduino} connected to an L298N driver via quadrature encoders.

Environment perception is based on an RPLidar A1 laser scanner, used both for map building and obstacle detection. Differential control was implemented using \texttt{ros2\_control} with the \texttt{diff\_drive\_controller}, and the tuning of the firmware PID gains was performed through a hybrid procedure: a Particle Swarm Optimization (PSO) algorithm identifies the First Order plus Dead Time (FODT) dynamic model of each motor and computes initial gains, which are then refined experimentally on the real hardware.

Validation was first performed in simulation with Gazebo, verifying kinematics, odometry, and control, before transferring the configuration to the real hardware while maintaining topic parity and YAML parameter structure. Mapping was performed using \texttt{slam\_toolbox} in asynchronous online mode, with graph optimization via Ceres (Levenberg–Marquardt) and loop closure enabled. Autonomous navigation was implemented with Nav2, using the NavFn global planner (A*) and the DWB local controller, orchestrated through a behavior tree with replanning at 4~Hz and a sequence of seven recovery actions. Additionally, an autonomous frontier-based exploration module was integrated, which allows the robot to generate its own navigation goals toward unexplored areas of the map without manual intervention.

\vspace{0.5cm}
\noindent\textbf{Keywords:} differential mobile robot, SLAM, \gls{ROS2}, Nav2, slam\_toolbox, autonomous navigation, Raspberry Pi, ros2\_control, frontier exploration, PSO, digital twin, differential control.
